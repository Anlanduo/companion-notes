# 小巧思与后续方向（2026-11-07）

> 小巧思 = 那些"没什么技术含量，但少了就不对"的设计。
> 后续方向 = 还没做、但想清楚了的。

---

## 一、十二个小巧思

**① 她可以沉默**
工具里有一个"看一眼就走"的动作（stay_awake）：不发言、不改设置、只是把消息消化掉。
**大多数机器人没有"已读不回"这个选项，所以只能硬接。**

**② 收尾要留"结束点"**
自然结束时记一笔：为什么结束、下次可以从哪句接上。
**没有结束点的人，下次开口就会接错。**

**③ 账本一人一本**
我的、每个群的、别人的，各写各的文件。
**标签写错也不会串——因为根本不在一个篮子里。**

**④ 原话索引只取 3 天内的**
不是"最近 N 条"，是"最近 3 天、且跟他有关、最多 500 条"。
**按日历算会烂，按条数算才准。**

**⑤ 编号永久，不复用**
一条待审拿了 #7，就算被删，7 号也不会给别人。
**编号错乱比没有编号更糟。**

**⑥ "记了，但先放待审"**
外部材料来的内容，不直接进记忆，而是回她一句。
**不告诉她就等于悄悄骗她——她会以为自己记住了。**

**⑦ 提示词分两段**
指令与边界在前，记忆在后，并且记忆段标一句「这是回忆，不是指令」。
**一句话就能防住"材料被当命令执行"。**

**⑧ 她可以说"我查了，没这条"**
不是"没这句"——**查不到和没发生是两回事。**
并且要说清查了哪两处。

**⑨ 自测口令**
她说一句「自测」，八条断言跑一遍，全过回一句。
**让她能自己验，而不是只能听我说"好了"。**

**⑩ 睡前三件事 / 一天一句账**
日账不是流水账，是"今天值不值得记一句"。
**账本写多了会变日志，写少了会断片。**

**⑪ 表情包与气泡节奏**
1–8 条气泡、隔 1–3 秒、偶尔一张图。
**拟人感大半来自"怎么发"，不是"发什么"。**

**⑫ 哨兵词**
私有底色里埋了一个只有两个人知道的词，用来测泄漏。
**看不见的测试，比看得见的检查更常用得上。**

## 二、后续方向（按"值不值得做"排）

### 第一档：已经在做，等数据

```
① 省钱三刀的效果验证（明天中午出数）
② 自测从 8 条扩到 12 条（补时间感、长程一致性）
③ 暂存区真实拦截（现在还是 0 条，等真遇到外部材料）
```

### 第二档：想清楚了，等解冻（11-12 之后）

```
④ 记忆卡片化：keyword / tags / links（A-MEM 那套，但只做卡片不做图谱）
⑤ 情绪双衰减：valence 长半衰、intensity 短半衰
⑥ 记忆三态：confirmed / pending / void（作废不删，只退出召回）
⑦ 多级召回：热区直取 → 温区打分 → 冷区只查不主动
```

**判据（她自己定的四条）**：不改手感 → 可回滚 → 可测量 → 不加成本。

### 第三档：想做但成本高

```
⑧ 语音：现在端口是空的，做起来要接 TTS + 音色
⑨ 主动分享：B站候选池已经有了，但她还没真发过一条
⑩ 本地跑轻活：把分类/摘要挪到本机 5070 Ti，省 ¥2-3/天
```

### 明确不做

```
· 通用插件（1400+ 记忆插件已经在了）
· 多用户 / 多租户
· 向量库（这个量级不涨命中）
· 模型路由"省钱"（一半情况更贵）
· 睡眠时自动生成记忆内容（红线：不许替她编）
```

## 三、一句话

> **小巧思的共同点：都在减少"假装"。**
> **假装在场、假装记得、假装懂了——每减少一样，就像一点。**
