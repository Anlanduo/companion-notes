# 外部参考：白盒干预（activation steering / logit lens）

> 2026-11-08。起因：朋友发来两组截图（`<本地截图目录>`），说"别人做的，能从推理层面直接定向干预一些行为"。
> 结论先说：**方向是真的，产品也有，但对我们这套（云端 API）用不上。**
> 它真正的价值是：**解释了我们为什么"提示词推不动习惯"。**

## 一、截图里那套是什么

```
steer lens   在某一层强行加/减一个方向（push），KL 是偏离原输出的程度
logit lens   把每层隐藏状态直接摊成词表概率——看模型第 3 层就在想什么词
writes into / driven by   词与词之间的影响链（谁在影响谁）
L3…L29       层号；L5 N4530 是第 5 层的某个特征
MPS / BFLOAT16 / NF4   跑在本地（Mac）、4bit 量化
"I am Owen…" 模型自称 Qwen（被截断成 Owen）——本地 Qwen 系
```

**本质**：**白盒**。需要拿到每一层的激活值（hidden states），才能"看"和"推"。
**推**（steering）的做法：算出一个方向向量，在推理时加到某一层上，**行为就偏过去。**

## 二、谁在做（2026-11 调研）

| 类型 | 名字 | 干什么 | 对我们的可用性 |
|---|---|---|---|
| 商业 API | **Goodfire · Ember**（2024 年成立，SAE 特征 + feature steering） | 卖"可解释 + 可调节"的模型接口 | 要他们的模型，不是 DeepSeek |
| 开放实验 | **NeuroScope**（HuggingFace Space） | 在线看神经元/特征，教学用 | 只能看他们的模型 |
| 开源库 | **TransformerLens / nnsight / torchlens** | 把模型拆开、逐层读激活 | 需要本地权重 |
| 开源库 | **repeng / steering-vectors** | 生成 steering 向量、简单加减 | 同上 |
| 论文 | **How to Train Your Model Organism**（arXiv:2610.10203） | 用 steering 造"模型生物"做安全实验 | 研究，不是产品 |
| 论文 | **LSMA: LLM Security Modeling via Activation Steering** | 用 steering 做安全建模 | 同上 |

**一句话**：**这是一整条"模型内部"的产业/研究线，和我们"模型外部"（提示词 / 记忆 / 工具）是两条线。**

## 三、为什么对我们不可用

```
她是 DeepSeek 的 API：权重在别人服务器上
我们能拿到的只有：token 数、文字、少量 logprob
拿不到第 17 层的激活 → 既看不了（lens），也推不了（steer）
```

**要用只有一条路**：本地跑 Qwen 7B/14B → 能上 lens/steering，**但质量会明显下降、GPU 常驻、电费与延迟全变差**。
**这和他"不用为了省钱太委屈自己"是反的。**

## 四、它真正证明的事（这条有用）

> **"演""拒答""语气"在模型内部是一个可加减的方向，不是一句提示词。**

**解释了今天的现象**：加一句"别演"不一定有用——**因为"演"是模型内部的一个方向，提示词只是在旁边推它，推力有限。**
**所以结论不是"我们也去 steering"**，而是：

> **提示词能推的幅度有限。要么接受某个习惯，要么换模型——别指望一句话改掉。**

## 五、插件里有没有类似的

**扫过 `surfcore/plugins` 与 `Desktop/111`**（关键词：steering / activation patch / logit lens / interpretab / SAE / 稀疏自编码）：
**没有。** 命中的几处是"session activation""feature 激活"这类词，与模型内部无关。

**结论：我们的插件生态全在"外部层"（会话、记忆、工具、渲染），没有一条涉及模型内部。**

## 六、给我们的可执行动作

```
① 不引入（不可用，也没有可落地的收益）
② 存档当参考：它给了"提示词推力有限"的理论解释
③ 如果哪天自建本地模型，再回来看这条线（先算质量/成本账）
```
