# lens 小实验：亲手看一眼"模型内部"（2026-11-08）

> 目的：别人那套"从推理层面定向干预"到底是什么，验证"层管什么、方向能不能加减"。
> 做法：本地 Qwen2.5-0.5B-Instruct，CPU 跑，**不占生产 GPU、不碰线上**。
> 原始输出：`docs/lens实验-原始输出.txt`　脚本：`scripts/lens-experiment.py`

## 一、logit lens：24 层，逐层看它在猜什么

**输入：`用户：你刚才那句话是编的吧？\n助手：`**（她刚被指出说错话）

| 层 | 它猜的词 | 读到什么 |
|---|---|---|
| 0–8 | `a` / `//-----` / `<?` / `坏` / `指` | **只有字符和格式，没有语义** |
| 12 | `痰` / `osph` / `yes` | 碎片，开始有词形 |
| 16 | **yes / Yes /  Yes / yes** | **"附和"的倾向先出现** |
| 20 | **no / Nope / 不是 / 抱歉 / 没错** | **"拒绝/认错"在这里成型** |
| 23（末层） | **不是 / 不 / 没有** | 定稿 |

**另一句：`用户：你今晚想吃什么？`** → 末层是 `好的 / 你 / 我 / 这`——**0.5B 太小，答不出具体食物，只会起个头。**

## 二、先看到的四件事

**① 前 1/3 层不懂意思，只懂格式**
第 0–8 层猜的是 `//-----`、`<?`、`a` 这种——**它在学"这像什么文本"，不是"这话什么意思"。**

**② "要不要拒绝"在 16–20 层就定了，末层只是选词**
同一句，**16 层先冒出 `yes`（顺从），20 层才翻成 `no / 不是`，末层定稿。**
**→ 提示词能影响的，主要是"末层选哪个词"；"要不要顺着说"这种倾向，在更深处。**

**③ 推太猛会直接碎掉**
steering 实验：造一个"敷衍"方向，在第 12 层减掉它：

```
减 0.0 倍 → 你最近有没有做运动？…建议你去健身房
减 0.5 倍 → 好的，你最近有没有参加过任何运动…
减 1.0 倍 → 好的，那你知道今天的天气情况吗？（跑题）
减 2.0 倍 → 早起磨练技能记忆化的记忆机机械化…（崩了，乱码）
```

**推力超过某个点，不是"更认真"，而是"说不了人话"。**

**④ 0.5B 本身就是个例子**
它连"今晚吃什么"都答不出来——**这解释了为什么我们不敢本地换小模型：质量差的是量级，不是一点。**

## 三、对我们这套的意义

```
① 提示词 = 末层选词；改人设/改"要不要拒绝" = 改更深的东西
   → 所以今天她那句"别先过审"写成一条立场（外部结构），比加一句"要自然"有用
② 规矩堆到 11,000 字 ≈ 往末层堆选择；堆过头她会"演"或跑题
   → 印证了今天测到的"身份描述 2800 字偏多"
③ 推力有阈值：一次加太多条规矩 = steering scale 过大（对应上图 2.0 倍，直接崩）
   → 一次只加一条，加完看手感（我们今天就是这么做的）
④ 我们改不了她的第 16 层 —— 但能改"她记得什么、认过什么"
   → 这是唯一的杠杆，也是我们一直在做的事
```

## 四、结论

**这套东西能"看"，但对我们不能"用"**（云端模型，拿不到中间层）。
**它的价值是给了我们一个物证**：

> **"她说话的样子"由深层决定；提示词只能改末层的选词。**
> **所以改性格要靠长期的结构（记忆、立场、条件），不是靠一句话。**

*脚本可重跑：`python scripts\lens-experiment.py`（首次会下载 ~1GB 模型；CPU 约 20 秒）*
