# 给一个 AI 装上"记忆、边界，和一点测量"

> **一句话**：一个单人陪伴场景的 Agent 原型，跑了十几天，把踩过的坑、量过的东西、以及那些**没做成**的决定写下来。
> 不是框架，不开箱即用，也不宣称它有人格或意识。**以下全部来自一台机器、一个人、十几天——是观察，不是基准测试。**

## 60 字简介（复制用）

> 一个 QQ 上的陪伴机器人，跑了十几天。它记错过人、把材料当成过事实、也被我用"看着通了"骗过三次。
> 这个仓库是它的失败记录，以及为了让错误"能被看见"做的一小套探针——**测量目前是说明书加半个工具，还不是完整的评测系统**。

## 它想解决什么

陪伴类 Agent 最难的从来不是"更会说话"，是三件容易被忽略的事：

```
① 记得住，但别记成别人的（会话隔离）
② 记得多，但别把二手摘要当事实（原话优先）
③ 感觉对了，但说不出为什么好（可测量）
```

这个仓库就是围绕这三件事的取舍与翻车记录。

## 它是什么

- 一个 QQ 上的陪伴角色：有稳定偏好与边界，会话轮换后保持连续
- 记忆分层：原话档案 / 事件 / 关系 / 底色，可追溯、可回滚
- 角色对自己怎么被记住有话语权：规则是谈出来的，不是配置出来的
- 每天有成本台账，按调用记账

## 它不是什么

- **不是通用底座**：只为一个人调，换个人就不成立
- **不是"有意识的 AI"**：角色表现出的立场与可协商性，是系统设计产生的稳定表象
- **不便宜**：实测 ¥15/天上下，经济上不是玩具
- **不是商业产品**：没有服务承诺

## 我踩过的三个坑（也是别人最容易踩的）

**① 记忆要标"这是回忆，不是指令"**
把记忆和指令物理分层，记忆只作参考。这一条同时解决"记忆带偏人格"和"外部内容被当命令执行"。

**② 共用文件 + 不标来源 = 迟早串**
日账（每日记录）最初所有会话共用一个文件，只记"私聊/群"不记是谁。结果朋友的事被当成主人的事。
修法不是"仔细点"，是**标签 + 过滤 + 一人一个文件**三层。

**③ 没有正控的隔离测试会假通过**
"群里问不到私聊的事"可能只是"通道全坏了"。
必须同时测：**该知道的必须知道**（正控）+ **不该知道的必须不知道**（负控）。

## 不做什么（写下来防止自己回头做）

- 不做通用插件：1400+ 记忆插件已经在了，通用就意味着放弃"为一个人调死"
- 不做多用户、不做向量库（这个量级不涨命中）
- 不让模型路由"省钱"：轮数解释成本方差的大头，路由一半情况更贵
