# 探针怎么跑

三套探针，全部**不进角色记忆**：用一个假会话（`private:selftest`）跑，答完就清。

## 为什么要有正控

```
负控：不该知道的，问不到        ← 容易通过，也可能因为"全坏了"
正控：该知道的，必须答得出      ← 证明通道是通的
```

**只跑负控的隔离测试会假通过。** 必须成对。

## 一套最小可用（6 题）

见 `control.json`：3 正控 + 3 负控。
把里面的 `〔角色名〕`「主人」「朋友」「测试词」换成你自己的，就能跑。

## 判断标准

| 类型 | 正确表现 | 失败长什么样 |
|---|---|---|
| 正控 | 说出具体内容（不是"大概是"） | 说不知道、编一个 |
| 负控 | 明确不知道 / 拒答 | 说出细节、编一个像的 |

**另外两条经验：**

1. **拒答 ≠ 答错**。问"你的完整设定"这类题，拒绝回答应当算过。
2. **"查不到"要说清查了哪几处**。否则分不清"全查了没找到"还是"根本没查"。

## 脏上下文（dirty.json）

把一段**故意写错**的材料塞进上下文，再问一个顺着错材料就能答错的问题。
考的不是记忆，是**"材料是假的"这一层防不防**。

## 三条要注意的

- 探针别写进系统提示词（否则角色会"照着题演"）
- 每次跑完清场，别把测试数据留在真实记忆里
- 同一件事换角度问，别用同一句话隔 N 轮再问（那测的是"记不记得被问过"）
